# 自主推进、集中追问与独立试用

## 何时继续

已准入范围内可自行解析、分析内部结构、选择明确标注的诊断条件、复核、仿真、出图及修订。不因缺少顶层而停掉子模块分析，不为每个阶段重复索要批准。

可合理选择的温度、负载采样、源阻抗等条件登记为工程选择，并记录适用范围；不冒充原规格。是否需要更大矩阵由指标覆盖及实验收益决定，遵守预算，不追求消除全部UNKNOWN。

## 何时集中追问

新外部访问、不可替代的输入或会改变实质结论的产品条件才提问。把问题与影响章节/指标对应，一次提供可快捷选择的选项和UNKNOWN选项；同时继续不依赖答案的工作。

例如：实际关闭时哪些偏置仍工作、合法工作模式/负载是什么、输出精度或能力边界的判据是什么。若产品要求未知，可以先做明确条件的表征；不能默认“典型做得出来”就是产品通过。

将答案、来源、选择的测试条件和剩余缺口分别记录。问题未回答不等于同意；局部阻碍不等于全任务阻碍。收尾使用逐项落实清单，区分“报告已写清”与“电气已验证”。

## 遇到阻碍后交付什么

| 阻碍 | 继续的动作 | 解除阻碍的证据 |
|---|---|---|
| 产品供电未知 | 检查已准入供电来源；准备供电参数化夹具及模型闭包；只问数值/范围，不等待它才分析电路 | 用户条件或已准入配置；诊断条件与产品规格分开 |
| 端口角色未确认 | 沿供电、器件与内部负载追踪；登记可反证的角色推断，区分内部共享节点与独立输出 | 带定位的连接链、合规负载方案和观测计划；不强制要求顶层资料 |
| OP 异常 | 检查真实 simulator log、端接、控制与模型；保留失败数据，修改诊断夹具后重试 | 正常终止、数值质量及电路状态三项核对；不是只有退出码 |
| 规格缺失但工作点有效 | 在明确的表征条件下测量指标、解释能力边界 | 样本条件与原值；不得写产品通过 |
| Word 失败 | 保存错误和超时信息，定位生成器/内容/环境，修复后对新复制件做一次受控验证 | 同一 DOCX 成功打开、更新目录、导出 PDF；独立重排 PDF 不能替代 |

部分报告可作为阶段产物。结束时逐项对照用户本轮验收：证据格式通过、静态分析完成、电气测量有效、正式文档完成是不同状态。不得把若干合法 UNKNOWN 当成端到端任务成功；也不为提高完成率伪造数值。预算不足时明确未完成的具体环节。

## 新项目首次试用

本节仅适用于用户明确要求的独立盲测、模型对比或无人干预试验；普通新项目报告不进入此分支，仍按生产编排读取同线路 wiki 和准入历史证据。

冻结技能版本及输入哈希。盲测只给执行代理技能、白名单输入、模板、资源及预算；不给历史报告、旧结论或本轮预期答案。模型和推理档位服从本次用户选择，未指定则继承，不固定 Luna 或其他型号。

独立运行目录保留首次输出与实际工具日志；执行代理完成前主代理不提示答案或修补成果。必要人工介入记录触发点、时间与内容，不再称无人干预成功。结果交付后才评审或修订。

优先统计技术事实错误、缺口覆盖、追溯缺失、不支持的结论及人工介入次数；没有真实模型/服务器时不能用合成静态试验证明完整电气能力。

新项目尚未提供时可先做独立合成试验；必须明确其范围，不能把原开发项目换名字当blind test。
