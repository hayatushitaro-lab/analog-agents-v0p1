# Analog Understanding

> 解释已有电路是什么、如何工作和实际表现如何，交付可复用的理解与验证材料。自主选择分析方法，不预设所有电路具备相同功能或指标。

## 1. 接收输入

- **必需：**原网表及依赖、对应工艺模型、仿真环境配置、输出位置。
- **可选：**参考文档、已知接线与模式、工作条件及仿真预算。

- 读取工作仓库 AGENTS.md，沿用其 Python、EDA、脱敏与检查约定；操作 Spectre 时使用可用的 spectre 技能和实际 API。
- 新建唯一工作目录，记录输入来源与版本，**原文件和已有运行只读**。
- 配置决定服务器和环境，不猜地址或凭证。

- 缺失非关键条件时提出有依据且明确标注的表征约定；接线存在互斥解释、依赖不可用或需要新增权限时集中询问，继续无关工作。
- 不因没有指标目标而停下。

## 2. 理解电路

- 沿真实层级分析至必要的底层器件，恢复接口、供电域、模式、拓扑、共享偏置/反馈、外部元件及模块依赖。
- 区分仿真外壳与真正 DUT；完整绑定位置型端口，避免重复实例化和误驱动输出。

- 解释关键机制、敏感节点与设计折中；**分别标记实现事实、用户确认、工程推断和未知**。
- **设计意图与调参规律需要证据**，不把经验猜测或历史文档自动当作实现事实。

- 按实际功能选择顶层和主要子模块的核心指标，**声明本轮测试范围**；交付时逐项说明已测、未测及原因。
- 结合文档检查遗漏，按实际电路决定适用性。
- 明确每项的条件、刺激、测量方法与无效判据，准备顶层/子模块 TB；无法独立测试的模块登记 in-situ 方法及理由。

## 3. 仿真 TT

- 从模型确定 nominal/TT 完整 section 组合，使用已确认供电与工作条件；温度未知时可声明 27 ℃ 为表征约定。
- 模型适用性尚未证明的条件注明限制。

- 先小批量确认实际端接、激励电平、偏置方向/电流和**内部工作状态符合声明场景**，再扩展主要模式、核心指标与 PVT 测试。
- **保留真实上电测试**；理想替代输入不能消除属于 DUT 的启动或共享反馈机制。
- 子模块结果与顶层代表性条件核对。

- 实际运行、保存日志/波形并用脚本提取指标。
- 每项测量明确**物理含义、目标状态、信号、触发/窗口、参考值和单位**，检查实际波形满足转换、稳态或恢复前提；电流/功率明确方向与计量边界。
- **执行成功不等于电气有效**。对告警或异常电压/电流调查其影响；影响未解释的相关结果保留为诊断/待定，不能直接进入有效基准。
- 夹具问题修 TB 后定向重跑；DUT 问题保留，**不修改器件参数或模型让结果符合预期**。
- 必要时做有界数值敏感性复核。

## 4. 仿真 PVT

- **在 TT 夹具和方法有效后**，按用户范围与模型支持选择工艺角、供电、温度及必要负载/控制点；先代表性点，必要时细化临界附近。
- 未支持或预算不足的项目逐项说明，不宣称完整 PVT。

- 运行前登记并发、超时、总次数/墙钟预算和有限重试次数。
- **每次尝试使用新 run ID**，记录实际条件、所用网表/模型及结果位置。
- 超时先查任务状态及日志，不重复提交仍在运行的任务。

- **同一指标跨工况保持定义一致**，汇总有效实测集合及极值条件。
- **保留失败/诊断点**；有限扫点极值不是连续全域保证。
- 真正阻塞或预算到限时交付有效部分及恢复条件，不能因已生成文件而提前结束已授权的重要补测。

## 5. 形成输出

- **输出三个核心逻辑文件**，并保留它们引用的 TB、脚本与原始结果：

- `understanding.yaml`：功能、接口/模式、拓扑、机制叙事、关键器件参数/模型属性、敏感性、模块依赖、绘图关系及各项证据/置信度。历史意图和未经验证的调参假设明确区分。
- `baseline.yaml`：稳定指标/场景 ID、TT/PVT 样本及汇总、数值与独立单位、条件、测量方法、run/data 引用、有效性和缺口。**没有可靠数值使用 null**；实测值不自动成为产品规格。
- `verification.yaml`：TB 与 standalone/in-situ 覆盖、fixture、测试—指标对应关系、测量契约、实际环境、批量运行/单场景重跑/再提取入口、运行结果及图/数据位置。

- 必要语义及跨文件关系见[三文件证据契约](references/evidence-contract.md)；按实际电路组织字段，不套固定模块或指标。
- 用简短入口说明列出输入来源、三个核心文件及验证资产的位置和使用方法。

- **样本与汇总使用同一套提取结果生成**；对主要指标抽查原始数据→提取→YAML的数值、单位和实际条件，不能只验证文件格式。
- 安全解析 YAML，检查 ID 唯一性、数值/单位、结果引用、样本与汇总一致性和主要模块覆盖。
- 区分文件生成、仿真完成、电气有效和规格达标；**没有明确规格时仅作表征**。
- 引用式交接说明解析基目录及必须保留的依赖；对外材料按环境约定脱敏。

- 交付简述主要产物、实际已测范围、重要发现、未完成项及恢复条件。
- 本任务不启动正向 sizing/optimizer 或 Word 报告流程；独立复核若未执行，如实标记。
