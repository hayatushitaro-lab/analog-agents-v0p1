# 三文件证据契约 · v1

供 analog-understanding 生成证据、analog-report 写作使用。约束必要语义和跨文件关系，不要求某类电路固定具有相同模块或指标，也不要求把原始波形内嵌 YAML。

三个文件使用一致的 `circuit_id` 和 `evidence_version`，各自登记 schema/version、生成时间及来源。引用默认相对该 YAML 所在目录解析；若不同，显式登记 base_directory。模块、claim、metric、scenario、test、sample、run 使用稳定 ID，不以自然语言标题代替 ID。同一 ID 的含义与来源可定位。

## understanding.yaml：电路是什么、如何工作

- **身份与来源：**DUT、原网表/依赖、工艺与模型版本、用户确认条件及工程假设。
- **接口与模块：**完整端口及总线位、方向/电压域/模式行为/端接；模块 ID、实际实例路径、功能边界、输入输出和共享依赖。
- **机制叙事：**主要信号/电流路径、反馈、启动/控制、拓扑原因与有依据的折中；分清实现事实、用户确认、推断和未知。每项主要结论有 claim ID、来源和置信度。
- **实现资料：**关键实例及实际参数/比例；实际器件 model 去重清单、类别/极性和有来源的属性。工作点写其条件及 sample/run 引用。未知耐压、密度、工作区等保持未知，不由实例尺寸补造。
- **图与风险：**可复用连接/框图或足以绘图的关系、敏感节点、观测异常/潜在风险及边界。概念图可由声明的机制组织，不自动当作逐器件连接图。

这份文件须能支撑“原理与实现”，不能只有模块名和指标列表；不要求恢复作者未经证实的历史思考，也不包含新工艺输入要求。

## baseline.yaml：实际表现如何

- **场景：**scenario ID、DUT/实例及 standalone/in-situ、模式/trim、实际各路供电与温度、完整model section组合、有效tnom、偏置目标与实际值、负载/外接网络、初始化和时序。环境温度与模型名义温度分开。
- **指标定义：**metric ID、物理量、独立单位、测量类型、信号、触发/起止窗口、参考值、阈值/保持判据、适用条件。电流/功率声明方向和计量边界；不同参考值或分析定义分成不同指标或明确变体。
- **样本：**sample ID、metric/scenario/test/run关联、YAML数值或null、有效性、提取结果及原始数据位置。执行成功与测量有效分开；无效数字留 observed_value，不进入有效基准。
- **汇总：**声明典型场景、有效样本集合及筛选条件、已测min/max和其样本/工况；同一条件的典型值不取所有角平均。数值从提取结果生成，不能另手写一套漂移的数字。
- **缺口：**未测、受阻、失败、无效、诊断、不适用分别说明原因、影响和恢复条件。容差/规格只有来源可靠时填写，没有目标不判合格。

关键值应能定位并复算。有限扫点极值不是连续范围保证；standalone结果不能自动成为顶层结果，未恢复或未启动不能用窗口终点/近零终值的百分比伪装成有效时序。

## verification.yaml：怎样得到、怎样复用

- **测试清单：**test ID、对象/模块/模式、对应metric IDs、TB和fixture、实际刺激、分析、保存信号、测量契约、声明范围及状态。一个测试可以产生多个指标；DC、STB和transient各自说明。
- **运行与方法：**唯一run ID、实际场景和options、模拟器版本、执行状态、日志/原始数据/提取文件；重提取与新仿真分开，命令说明解析基目录，不依赖未随交付保留的临时指针。
- **图与数据：**可用图的路径、类型、对应test/metric/sample/run及绘图数据/脚本。没有现成图时引用足够的实际数据和提取方法；没有数据时写缺口，不能让写作者编曲线。
- **覆盖：**顶层、主要模块及变体的standalone/in-situ覆盖和理由；每项适用验证保留计划/实际状态/未完成原因，包括只有功能观察、没有数值指标的测试。
- **其他记录：**已执行的审查/脚本/物理验证及日志；未执行的PERC/DRC/LVS/PEX如实说明。记录仿真预算/停止依据与独立复核是否实际执行。

## 三文件之间必须一致的关系

1. understanding里的主要模块、模式和claim可定位到verification的测试/来源，纯拓扑事实可引用静态提取资料，不强求都有仿真。
2. baseline的metric/sample对应verification的test/run，实际条件和测量定义一致；报告中每项主要数字回到这个关系。
3. 图、正文和汇总消费同一组样本；不同初始化、接收负载、模型、参考值等只在已声明可比规则下汇总。
4. 文件生成、仿真成功、指标有效、规格达标、报告已渲染分别表达。异常影响未解释时保留诊断/待定范围。

旧三文件格式无需强制重写历史资产；在新工作区记录实际字段映射、原文件版本及未满足语义，不把缺失字段补成已验证。报告发现新事实/新派生数值时请求证据层修订；只做同值工程单位显示换算无需新增电气结论。
