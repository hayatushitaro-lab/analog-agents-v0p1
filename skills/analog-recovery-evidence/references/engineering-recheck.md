# 分析与实测交叉复核工作卡

ANALYST/VERIFIER/REVIEWER 在已有角色任务内使用，不新增角色或一堆手填文件。结果记入原有 review findings、claims 和 metrics。

1. **端口到器件的可达性**：扫外部参数前，从夹具激励沿 DUT 实参、形参追到实际器件。夹具中存在源而 DUT 未连接，不叫 trim 验证。常量输出只能说明该夹具下无响应，不证明所有代码等效。内部理论可调性与当前顶层暴露能力分开。
2. **方程与 OP**：写物理机制及假设，用已知尺寸/参数计算可算项。需要 gm、寄生电容、增益时抽取有效 OP/模型 metadata 或做对应实验；不能凭常见电路填典型值。简单 RC 数量级与带宽不符时解释其他加载/极点，不能略去矛盾。
3. **指标矩阵**：先区分用户范围、实际温度/电压采样集合、典型工况、产品保证；不同指标的实际覆盖可以不同。共同工作条件表不能仅从第一条 27℃ OP 填成 27/27/27。核对原生日志温度和实际 sweep。min/max 只来自同一量、同一提取定义的可比集合；PSRR 固定频点比较 PVT，频率响应范围另列。
4. **旧数据也要读**：复用结果时核对 nominal 是否已有、瞬态阈值/窗口、符号和单位。无 typical_case_id 不等于无数据；允许明确记录后选的参考工况，不冒充原始规格。不把扫描终点当极限，不将 PM 的有限样本推广到全温全负载绝对稳定。
5. **波形→图→正文**：画图直接读可定位的原始数据/受控导出；数值标注由同一数据计算。审查绘图脚本是否使用公式生成曲线、硬编码图例数字或裁剪隐藏失败区间。解析曲线用 DERIVED，概念图用 INFERRED，不因坐标轴完整就叫 SIMULATED。图源检查写入既有 review，不再制造一套“证明自己正确”的数值。
6. **相互矛盾**：有明显过冲时不能写启动无过冲；窗口未稳定不能写快速建立；电容增大后仍有明显波动不能写低于某阈值。先列原数据与正文的具体冲突，区分版本、条件、阈值不同，不能套常识抹平观测。
7. **工程意义**：风险和布局建议要有电流/信号路径依据；没有版图不阻止前端分析。没有版图或工艺规则就不指定无来源的金属阻值、线宽和已实现匹配。存在内部 trim 不证明熔丝、NVM 或金属 ECO 已预留。

REVIEWER 的输入必须含实际夹具/相关连接、主要波形提取结果、待交付正文与图注；只审 evidence JSON 或模拟“投票通过”不足。重点审新增数值、范围声明、理论/实测标注、控制可达性和异常解释。发现错误先修局部，不强制新仿真来解决纯写作问题。

判定成功看解释能否被连接和数据支撑，不看支持ID数量。质量包里的 check 由待审数字反算再对比自身属于循环论证；源 hash 只能证明文件身份，不能证明其内容是真实仿真或说明正确。

## 修订旧证据与验证物理量（v0.11）

- 旧包只读不等于冻结其错误：新建带 parent 来源的修订包/差异记录，同步修改定义、单位、典型工况和覆盖；再生成报告。旧复核记录只证明当时的对象，不能只更新正文hash沿用通过标签。
- 独立复核至少核对一个“数值正确但意义可能错误”的量。例如误差−0.7%、下限−1%时，剩余余量是0.3个百分点，不能把0.7%称为余量。说明参考分母与上下限；电压差和百分比不能混用。
- 量纲检查中的identity(Vout)不能替代ΔVout、启动峰值或输出偏差的计算。复合量需要实际原数据提取和受控计算；若由转换文件供校验，明确它是计算导出、绑定原文件和脚本，不标成模拟器原生输出。
- 未接入DUT的激励扫描保留为夹具诊断，不以“输出不变”标成功能Y。降级也要传到指标表、验证清单和结论。
- 相同数值的不同定义不要强行统一：裕量/偏差、VDD恢复下限/压差、参考传递/电源PSRR均须分别核对。
